Amadeus Self-Service 준비 요약

1) 계정 및 접근
- Amadeus 개발자 포털(https://developers.amadeus.com)에서 계정 생성
- Self-Service(또는 Test/Sandbox) 애플리케이션 생성 후 API Key(Client ID) 및 Secret 획득
- 테스트용 엔드포인트: https://test.api.amadeus.com
- 운영 엔드포인트: https://api.amadeus.com

2) 인증
- OAuth2 Client Credentials 사용
- 토큰 발급 예시:
  POST /v1/security/oauth2/token
  grant_type=client_credentials&client_id=YOUR_API_KEY&client_secret=YOUR_API_SECRET
- 토큰은 TTL이 있으므로 캐싱 후 만료 시 재발급

3) 주요 엔드포인트(주요 사용 케이스)
- 항공편 검색(Flight Offers): /v2/shopping/flight-offers
- 요금/가격 확인: /v1/booking/pricing 또는 /v1/shopping/flight-offers/pricing (버전 확인 필요)
- 예약/발권(Booking): /v1/booking/flight-orders (실제 예약은 추가 권한/계약 필요할 수 있음)
- 참조데이터: 공항·도시 검색, 항공사 코드 등

4) 샘플 호출
- 토큰 발급(curl):
  curl -X POST "https://test.api.amadeus.com/v1/security/oauth2/token" \
    -H "Content-Type: application/x-www-form-urlencoded" \
    -d "grant_type=client_credentials&client_id=YOUR_API_KEY&client_secret=YOUR_API_SECRET"

- 항공편 검색(curl):
  curl -X GET "https://test.api.amadeus.com/v2/shopping/flight-offers?originLocationCode=ICN&destinationLocationCode=LAX&departureDate=2026-09-01&adults=1" \
    -H "Authorization: Bearer ACCESS_TOKEN"

5) 개발·운영 고려사항
- Sandbox에서 먼저 통합 테스트(요청/응답 포맷, 에러 케이스 파악)
- 요금/예약 관련 기능은 계약·약관 확인 필요(운영 승인 요구 가능)
- 속도·요율 제한(Rate limits) 및 비용 모델 확인
- PII(여행자 정보)와 관련한 개인정보보호 및 규정 준수 검토

6) 기술 스택·라이브러리
- 공식 Java SDK: amadeus-java (Maven/Gradle 의존성 확인)
- 직접 HTTP 호출: Spring WebClient 또는 RestTemplate 사용 가능
- 토큰 캐싱·재시도(Resilience4j), 회로 차단, 캐싱(Caffeine/Redis)

7) 참고·다음 단계
- Amadeus 개발자 문서 확인: API 버전·엔드포인트 정확 확인
- 샌드박스 키 발급 및 간단한 통합 PoC 구현
- 예약(Booking) 기능 전 개발 전 법적·비즈니스 검토 필요

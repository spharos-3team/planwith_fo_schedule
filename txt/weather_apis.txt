날씨 API 옵션 요약

1) OpenWeatherMap
- 엔드포인트: https://api.openweathermap.org/data/2.5/
- 주요 기능: Current Weather, One Call (현재/예보/히스토리), 날씨 아이콘
- 인증: API Key
- 샘플 호출:
  curl "https://api.openweathermap.org/data/2.5/weather?q=Seoul&appid=YOUR_KEY&units=metric"
- 장점: 무료 티어 제공, 넓은 커버리지

2) Weatherbit
- 엔드포인트: https://api.weatherbit.io/v2.0/
- 기능: 현재/예보, 대기질 데이터 등
- 인증: API Key

3) AccuWeather
- 파트너 기반 API, 가입·키 발급 필요
- 높은 정확도(상용), 비용 및 이용조건 확인 필요

4) Visual Crossing / Meteostat 등
- Visual Crossing: 상용·예측·히스토리 데이터
- Meteostat: 주로 역사적 기상 데이터(연구/분석 용도)

5) 통합 고려사항
- 사용 목적(현재·단기예보·중장기예보·히스토리)에 따라 공급자 선택
- 응답 포맷(시간대, 단위) 표준화 필요(도메인 DTO 설계)
- 요금·요청 한도 확인, 캐싱으로 비용 최소화
- 지역별 커버리지 확인(해외·지역 특화)
- Java 클라이언트: 공식 SDK 또는 Spring WebClient로 래핑

6) 샌드박스와 테스트
- 일부 제공자는 무료 티어/샌드박스 제공
- WireMock을 이용한 외부 API 모킹 권장
